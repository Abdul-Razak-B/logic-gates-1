Identity Law

AND Form: A · 1 = A
OR Form: A + 0 = A
Definition: A variable combined with a logical constant (1 for AND, 0 for OR) retains its original value. The constant acts as a transparent pass-through.
Real-World Example: A smart lock (A) connected to a guaranteed power supply (1). The door unlocking depends entirely on whether the smart lock triggers (A · 1 = A).

2. Structural Laws

Commutative Law

A · B = B · A
A + B = B + A
Definition: The sequence or order of input variables does not affect the final logical outcome. Inputs can be safely swapped.
Real-World Example: Two keyholes required to open a vault (A and B). Inserting key A then key B opens the door just the same as key B then key A.

A·(B·C) = (A·B)·C
A+(B+C) = (A+B)+C
Definition: When evaluating three or more variables with the same logical operator, the grouping of the variables does not change the output.

Distributive Law

A·(B+C) = (A·B) + (A·C)
A+(B·C) = (A+B) · (A+C)
Definition: A logical operator can be distributed across a parenthesized group, exactly like multiplying variables in algebra.
Real-World Example: A bank login requires Password (A) AND (SMS (B) OR Email (C)). This is identical to checking (Password AND SMS) OR (Password AND Email).
