Fundamental 01

Identity Law

A variable combined with a logical constant (1 for AND, 0 for OR) retains its original value seamlessly.

A · 1 = A
A + 0 = A

Fundamental 02

Inverse Law

A variable combined with its exact opposite yields a constant state (AND = 0, OR = 1).

A · A' = 0
A + A' = 1
Simulate Inverse Law →
Structural 03

Commutative Law

The sequence or order of input variables does not affect the final logical outcome.

A · B = B · A
A + B = B + A
Simulate Commutative Law →
Structural 04

Associative Law

When evaluating three or more variables with the same operator, grouping does not change output.

A·(B·C) = (A·B)·C
A+(B+C) = (A+B)+C
Simulate Associative Law →
Structural 05

Distributive Law

A logical operator can be distributed across a parenthesized group, just like algebraic multiplication.

A·(B+C) = (A·B)+(A·C)
A+(B·C) = (A+B)·(A+C)

Optimization 06

De Morgan's Theorem

Inverting a whole expression changes internal operators (AND ↔ OR) and negates each variable.

(A · B)' = A' + B'
(A + B)' = A' · B'
